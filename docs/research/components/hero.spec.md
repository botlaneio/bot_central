# Header and hero
Navy announcement, white navigation with aligned horizontal controls, then hero body with a large, light-weight Sohne heading and violet invite button. At 1440px the hero heading begins around x=200 and y=294 with a 55.2px line height. The artwork is positioned behind the heading, clipped by the rectangular hero shell. Reference hero uses a canvas and supplies desktop, tablet and mobile fallback artwork. The build uses those fallback images and a CSS-driven logo track. Product menu links go to corresponding homepage sections. The invite, sign-in and sales controls show a demo dialog.
