# Responsive and interaction observations
Measured heading sizes at 1440 / 768 / 390px: hero 48 / 40 / 34px, standard sections 32 / 28 / 22px, global commerce 56 / 48 / 34px. Hero copy block widths: 958 / 687 / 343px. On mobile only the opening hero statement is visible and the navigation collapses to a menu button. On desktop the 36px announcement stacks over the 76px navigation, with the colored hero artwork behind the navigation and above the logo strip. The logo strip moves horizontally.
The product navigation opens an expanded panel, and the billing tile opens a dialog with a focused Close dialog button. Enterprise content exposes an accordion, while startup stories, testimonials and news expose directional or indexed carousel controls. Demo action buttons open local UI, and product panels use illustrative data.
